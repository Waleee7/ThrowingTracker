### Architecture notes for whoever executes next

- `units.ts → parseDistanceToMeters` handles `199' 6"`, `199-6`, decimal ft.
- Tab nav is a top bar: flex, `overflow-x: auto`, `min-width: 65px` per tab —
  7 tabs scroll slightly on narrow phones; real nav architecture belongs to the
  Broadcast Finish deep-dive.
- `globals.css` bottom layer (~line 4230+) is the broadcast override layer; comments
  mentioning "Fraunces" there are stale — display font is Anton via `--font-display`.
- Coach route returns `x-coach-mode: live|fallback` header; corpus + athlete context
  are prompt-cached.
- Register model: `@theme` tokens are dark values; `.dark` ON = dark register;
  `:root:not(.dark)` overrides = white/paper (the default for new users).
